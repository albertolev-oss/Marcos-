# Rodilla 3D Marcos

## Agente Web Clínico

Este repositorio contiene ahora un MVP separado para controlar desde una PWA un Chromium privado vía noVNC. Opera en **modo lectura por defecto**, pausa para autenticación manual y aplica controles contra fuga de credenciales, navegación fuera de la allowlist y prompt injection. Véanse [arquitectura](docs/ARCHITECTURE.md) y [operación](docs/OPERATIONS.md).

> No está desplegado ni validado con datos reales. No habilitar escrituras clínicas ni usar datos de pacientes sin revisión de seguridad, privacidad y cumplimiento.

Visor 3D educativo de rodilla/protesis para traumatología.

## Uso

Abrir `index.html` desde GitHub Pages.

## GitHub Pages

Activar en:

`Settings → Pages → Deploy from branch → main → /root → Save`

URL esperada:

`https://albertolev-oss.github.io/Marcos-/`

Modelo educativo aproximado. No sirve para planificación quirúrgica real ni navegación intraoperatoria.
